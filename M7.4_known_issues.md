# M7.4 — Known Issues

## NLU Generalization

### KI-001 — Shopping expense misclassification

**Input**
> Hôm qua mình thanh toán 420 nghìn cho đôi giày

**Expected**
- Intent: dd_expense
- Entity amount: 420 nghìn

**Observed**
- Intent: dd_income
- Confidence: ~0.519
- Entity 420 nghìn được nhận thành udget_limit

**Classification**
NLU generalization limitation.

**Decision**
- Do not retrain M7.2 for this isolated case.
- Keep the current NLU model frozen.
- Keep this case in regression/generalization evaluation.
- Revisit when a broader set of similar shopping/payment examples is available.

**Impact**
The case demonstrates an NLU classification/entity extraction limitation. Financial decision logic remains responsible for preventing unsupported transactions from being accepted.
